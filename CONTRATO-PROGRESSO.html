Decisões técnicas confirmadas

  • 100% Go com embed.FSBackend, templates HTML, OpenAPI 3.1 e interface Split-Screen empacotados no binário único ia-infinito-contracts.exe.
  • SQLite em modo WAL (modernc.org/sqlite)Driver puro Go (sem CGO) com tabela contracts, índices e cache cnpj_cache.
  • S3 com fallback localUpload via aws-sdk-go-v2 quando configurado no .env e gravação automática em ./data/pdfs no modo local.
  • html/template + chromedp v0.23.1Pool persistente gerando PDF A4 com cabeçalho da IA Infinito e paginação em todas as páginas.
  • Documentação interativa via ScalarRota /docs servindo OpenAPI 3.1 e endpoints compatíveis em /api/* e /api/v1/*.
  • Deploy contínuo GitHub Actions → GHCR → CoolifyImagem linux/amd64 com Chromium, tag :coolify, webhook de deploy autenticado por token e pull_policy: always para garantir a versão nova a cada push.
